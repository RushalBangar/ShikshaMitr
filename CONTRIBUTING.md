# Contributing to ShikshaMitr

First off, thank you for considering contributing to ShikshaMitr! It's people like you that make ShikshaMitr such a great tool for students and faculty alike.

## How Can I Contribute?

### Reporting Bugs

If you find a bug, please create an issue in the repository. Make sure to include:
- A clear and descriptive title.
- Steps to reproduce the bug.
- Expected behavior vs. actual behavior.
- Screenshots if applicable.

### Suggesting Enhancements

Have an idea to make ShikshaMitr better? We'd love to hear it! Open an issue describing the feature and why it would be useful.

### Contributing Code

1. **Fork the repository.**
2. **Clone your fork locally:**
   ```bash
   git clone https://github.com/your-username/ShikshaMitr.git
   ```
3. **Create a new branch** for your feature or bugfix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** ensuring that the code follows the existing style and conventions.
5. **Test your changes** locally to ensure everything works as expected.
6. **Commit your changes** with a clear and descriptive commit message:
   ```bash
   git commit -m "Add some feature"
   ```
7. **Push to the branch:**
   ```bash
   git push origin feature/your-feature-name
   ```
8. **Submit a Pull Request** to the `main` branch of the original repository.

## Coding Guidelines

- **Frontend:** Write clean, semantic HTML and modular CSS. Prefer Vanilla JS without heavily relying on external libraries unless necessary.
- **Backend:** Follow PEP 8 style guide for Python. Ensure any new API endpoints are documented appropriately using FastAPI's built-in features.

Thank you for contributing!
