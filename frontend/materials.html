Maharashtra SSC

2025 SSC Mathematics

Time Allowed: 2 Hours Maximum Marks: 40

Section A: Multiple Choice Questions (4 Marks)

Q1 (A): Solve the quadratic equation: 2x² - 5x + 3 = 0. Find the value of discriminant (Δ).

Q2 (A): For an Arithmetic Progression, if a = 3.5, d = 0, find t₁₀₁.

Q3: State the Pythagoras theorem and solve for hypotenuse when base = 6 cm and height = 8 cm.

Official Step-wise Marking Scheme Examiner Verified ✓

Solution & Step Marks Breakdown:

Ans 1 (A): For 2x² - 5x + 3 = 0, comparing with ax² + bx + c = 0:
a = 2, b = -5, c = 3 [0.5 Mark]
Discriminant Δ = b² - 4ac = (-5)² - 4(2)(3) = 25 - 24 = 1. [0.5 Mark]

Ans 2 (A): Formula tₙ = a + (n - 1)d.
t₁₀₁ = 3.5 + (101 - 1)(0) = 3.5. [1 Mark]
