Q4: If root of 2x² + kx − 6 = 0 is 2, find k. Correct (+1)

Since x = 2 is a root: 2(2)² + k(2) − 6 = 0 ⇒ 8 + 2k − 6 = 0 ⇒ 2k + 2 = 0 ⇒ 2k = −2 ⇒ k = −1.
